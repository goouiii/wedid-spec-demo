# WEDID · 화면 정의서와 기능명세서 + Live Demo

잇타 3팀 WEDID(MVP v2.0, 11/14 최종)의 화면 정의서 24개 화면 · 기능명세 20개를 한 사이트에서 보고, DESIGN 하이파이 스타일로 다시 그린 화면을 직접 눌러볼 수 있는 문서 사이트예요.

- **전체 흐름 보기** — 핵심 흐름(첫 화면 → 질문 5개 → 결과 → 로드맵 → 예식장 · 스드메 계약)과 화면 카드
- **문서 보기** — 화면 개요 · 주요 동작 · 상태/예외 표 · 확인 필요 항목, 1440px 프레임 위 번호(피그마 화면설계서 번호와 동일), 관련 기능명세와 데모 구현 상태
- **시연하기** — 문서와 독립된 Live Demo. 로그인 실패 · 짝꿍 합류 · 짝꿍 체크 · 초대 링크 접속 · 예식일 앞당기기는 시뮬레이터로 재현

원문: Notion `잇타 3팀 > PM > 화면 정의서 · 기능명세서 (MVP 11/14)` (데이터베이스 2개), Figma 화면설계서.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 생성 (상대 경로라 GitHub Pages · Vercel 어디서나 동작)
```

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/data/spec.json` | 화면 정의서 · 기능명세서 원문 데이터 (Figma 화면설계서에서 추출) |
| `src/data/spec.ts` | 타입, Notion 행 ID, 데모 구현 상태(IMPL), 핵심 흐름 |
| `src/data/mock.ts` | 금액 · 예시 업체 · 로드맵 단계 Mock Data (오늘 = 2026.11.24 고정) |
| `src/demo/state.tsx` | 시연 상태 · reducer · 화면별 기본 상태(seedFor) · 번호 헬퍼(useAnno) |
| `src/screens/` | 하이파이 화면 (데스크톱 1440) |
| `src/portal/` | 전체 흐름 · 문서 · 시연 페이지, 번호 프레임 |

## Mock 원칙

- 금액은 화면 정의서 예시값(예식장 1,550만~1,900만 · 스드메 250만~350만)에 맞춘 Mock이에요.
- 업체는 모두 "예시 ○○" 이름이고, 업체 사진 · 소개글은 쓰지 않아요(정책: 공식 채널로만 연결).
- 카카오 · 구글 로그인, 초대 링크 발급, 결과 공유 페이지는 실제로 처리하지 않아요.
