# WEDID · 화면 정의서와 기능명세서 + Live Demo

잇타 3팀 WEDID의 Figma **[DESIGN - 디자인] 페이지(node 135-472)** 프레임 56개를 기준으로 쓴 화면 정의서 56개 · 기능명세 31개(요구사항 FR 20개 + DESIGN에서 추가된 FR-D 11개)를 한 사이트에서 보고, 같은 화면을 React로 다시 그려 직접 눌러볼 수 있는 문서 사이트예요.

- **전체 흐름 보기** — 핵심 흐름(첫 화면 → 질문 → 결과 → 로드맵 → 예식장 후보 · 비교 → 스드메)과 DESIGN 6개 섹션별 화면 카드
- **문서 보기** — 화면 개요 · 주요 동작 · 상태/예외 표 · 확인 필요 항목, 1440px 프레임 위 구성 요소 번호(이 문서에서 붙인 번호), 관련 기능명세와 데모 구현 상태
- **시연하기** — 문서와 독립된 Live Demo. 로그인 실패 · 짝꿍 합류 · 짝꿍 체크 · 초대 링크 접속 · 만료 링크 · 예식일 앞당기기는 시뮬레이터로 재현

원문: Notion `잇타 3팀 > PM > 화면 정의서 · 기능명세서` (데이터베이스 2개), Figma `잇타 3팀 > [DESIGN - 디자인]` (node 135-472).

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 생성 (상대 경로라 GitHub Pages · Vercel 어디서나 동작)
```

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/data/spec.json` | 화면 정의서 · 기능명세서 원문 데이터 (Figma DESIGN 135-472 프레임 기준) |
| `src/data/spec.ts` | 타입, Notion 행 ID, 데모 구현 상태(IMPL), 핵심 흐름 |
| `src/data/mock.ts` | 금액 · 예시 업체 · 로드맵 단계 Mock Data (오늘 = 2026.11.15 고정 · 디자인의 D-334 기준) |
| `src/demo/state.tsx` | 시연 상태 · reducer · 화면별 기본 상태(seedFor) · 번호 헬퍼(useAnno) |
| `src/screens/` | 하이파이 화면 (데스크톱 1440) |
| `src/portal/` | 전체 흐름 · 문서 · 시연 페이지, 번호 프레임 |

## Mock 원칙

- 금액은 디자인 예시값(예식장 1,550만~1,900만 · 스드메 250만~350만 · 총 1,800만~2,250만)에 맞춘 Mock이에요.
- 디자인에는 실제 업체명 · 사진이 들어가 있지만, 시연은 모두 "예시 ○○" 이름과 일러스트로 바꿨어요 (사용 권한 확인 전).
- 카카오 · 구글 로그인, 초대 링크 발급, 결과 공유 페이지는 실제로 처리하지 않아요.
